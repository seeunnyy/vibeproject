## 1. 한 줄 정의
공동소유 자산의 지분과 비용을 기록하고, 합의된 규칙에 따라 공동소유를 종료하는 모바일 웹 서비스.

## 2. 문제 (Problem)
1. **지분·부담이 불명확** — 함께 산 물건의 소유 지분과 비용 분담을 구두나 메신저로만 정해, 시간이 지나면 누가 얼마를 냈고 현재 소유 비율이 어떤지 확인하기 어렵다.
2. **기록 누락으로 재계산 불가** — 추가 구매비·수리비·배송비가 기록되지 않아, 구성원별 실제 부담액과 소유 비율을 다시 계산하기 어렵다.
3. **종료 규칙 미합의로 분쟁** — 이사·졸업·동아리 해산 시 매각·인수·폐기 중 무엇을 적용할지 미리 정하지 않아, 매각 금액·잔존가치에 대한 의견 차이가 정산 갈등으로 이어진다.

이 중 **우선 해결할 문제는 3번(종료 시점 분쟁)** 이다. 1·2번 기록은 3번 정산을 신뢰할 수 있게 만들기 위한 전제로 다룬다.

## 3. 사용자 (Users)

### 3.1 타겟
| 구분 | 대상 | 특징 |
|---|---|---|
| 주요 | 룸메이트 | 냉장고·청소기·가구·공용 주방용품을 공동 구매하는 20~30대 대학생·사회초년생. 구성원별 납부액이 다를 수 있음 |
| 주요 | 동아리 구성원 | 카메라·음향장비·행사 물품·공구 등 공용 자산을 관리 |
| 부차 | 초보 학습자 | 공동소유·자산 토큰화의 기본 원리를 학습하려는 사람 |

### 3.2 공통 특성
- 전문 회계·금융 지식 없음
- 모바일에서 빠르게 입력할 수 있는 단순한 서비스 선호
- 메신저 대화만으로 합의를 관리하는 데 불편을 느낌
- 분쟁이 생기기 전에 기준을 남기고 싶어 함

### 3.3 1차 검증 대상 (4주 내 테스트)
룸메이트 3명이 공동 구매한 가전 1건. 이사 시점의 **매각 정산** 시뮬레이션을 실제로 돌려 본다.

## 4. 가치 (Value)

### 4.1 핵심 가치
자산의 전 생애 — **구매 시 합의 → 보유 중 비용 기록 → 종료 시 정산** — 를 하나의 흐름으로 연결한다. 구매 시점에 앱으로 합의(지분·관리자·규칙)를 문서화하고, 공동소유를 종료해야 하는 시점에 분쟁을 줄인다.

### 4.2 차별점
- 가계부·정산 앱은 **지출을 나누는 데** 집중하지만, 우리몫은 **자산 자체와 지분·종료 규칙**을 관리한다.
- 복잡한 금융 용어나 실제 토큰 발행 없이, **지분 발행 · 가치 평가 · 청산**이라는 자산 토큰화의 핵심 개념을 일상적인 공동소유 사례로 체험하게 한다.
- 외부 시세·거래 API 없이 사용자 입력값과 사칙연산만으로 동작 → 4주 내 안정적인 구현·시연이 가능하다.

### 4.3 성공의 모습
첫 사용자가 도움 없이 모바일에서 **자산 생성(참여자·관리자·납부액) → 납부액 합계 검증 → 비용 2건 기록 → 매각 정산 확인 → 요약 공유**까지 계산 오류 없이 완주한다.

## 5. 범위 (Scope)

### 5.1 이번 MVP 포함
- **자산 등록**: 물건명, 구매일(선택), 총 구매금액, 참여자, **관리자 지정(선택)**, **합의 메모(선택)**, 납부액 또는 균등 지분
- **지분 자동 계산** 및 **납부액 합계 = 총 구매금액** 검증
- **공동비용 기록**(수리비·추가 구매비·배송비)과 부담자, 참여자별 낸 비용 단순 합계 표시
- **종료 규칙 = 매각** 1종과 합의 메모 기록
- **매각 정산**: 매각가 입력 → 구성원별 받을 금액 계산 + 합계 검증
- 모든 계산 결과와 합의 내용을 담은 **읽기 전용 공유 요약**(텍스트 복사)

### 5.2 이번 MVP 제외 (Non-goals)
- **인수 정산 / 폐기 정산** (규칙은 02 부록 A에 보존, 구현은 다음 버전)
- 누적 부담액을 정산에 반영하는 계산
- 결제·송금·정산 실행
- 복잡한 인증 / 사용자 계정
- 실시간 협업
- 대용량 파일 업로드
- 다수 외부 API 연동(시세·거래 API 없음)
- 자동 감가상각·중고 시세 추정
- 예시 데이터 자동 불러오기

### 5.3 다음 버전 후보
- 종료 규칙 인수·폐기 시나리오 (02 부록 A)
- 누적 부담액을 정산에 반영
- 자산·참여자·비용 편집
- 자산 여러 건에 대한 대시보드·검색
- 합의 이력(버전) 관리
- 참여자 초대·확인 절차
