## 1. 용어 정의
| 용어 | 뜻 |
|---|---|
| 자산(Asset) | 공동으로 구매·소유하는 물건 1건 |
| 참여자(Member) | 자산의 지분을 가진 사람 |
| 관리자(Manager) | 자산을 실제로 보관·관리하기로 합의한 참여자 1명 (선택) |
| 합의 메모(Agreement Note) | 구매·종료에 관한 자유 서술 합의 내용 (선택) |
| 납부액(Contribution) | 참여자가 구매 시 실제로 낸 금액 |
| 지분율(Share) | 참여자의 소유 비율(%). 납부액 비율 또는 균등으로 산출되며, 계산 성질상 합계는 100% |
| **납부액 검증** | **참여자 납부액의 합계가 총 구매금액과 같은지 확인하는 것** (100% 검증의 실제 대상) |
| 비용 내역(Cost Entry) | 보유 중 발생한 지출(수리비/추가 구매비/배송비)과 부담자 |
| 낸 비용 합계 | 참여자가 부담자로 기록된 비용 내역의 단순 합 (표시 전용, 정산 미반영) |
| 종료 규칙(Termination Rule) | 공동소유를 끝내는 방식. **MVP는 매각만.** 인수·폐기는 다음 버전 |
| 매각가(Sale Price) | 종료 시점에 사용자가 입력하는 자산 매각 금액 |
| 정산(Settlement) | 종료 규칙과 매각가로 계산한 구성원별 받을 금액 |
| 요약(Summary) | 모든 합의·계산 결과를 담은 읽기 전용 화면 |

## 3. 계산·검증 규칙 (Rules)
> 규칙만 기술. 알고리즘 구현은 04.

- **R-1** 지분율 = 납부액 ÷ 납부액 합계(납부액 모드) 또는 100 ÷ 참여자 수(균등 모드). 표시는 소수 첫째 자리 반올림, 반올림 잔여(±0.1%)는 납부액이 가장 큰 참여자(균등이면 첫 참여자)에게 배분. **지분율 합계는 계산 성질상 항상 100%이며, 이는 검증 대상이 아니다.**
- **R-2** 균등 분할: 100 ÷ 참여자 수. 나머지는 첫 참여자에게 가산.
- **R-3** 낸 비용 합계 = 해당 참여자가 부담자로 기록된 모든 비용 내역의 단순 합. **정산 계산에는 사용하지 않는다.**
- **R-4** 매각 정산: 구성원 받을 금액 = 매각가 × 지분율. 받을 금액 합계 = 매각가.
- **R-5** (삭제 — 인수 정산은 부록 A로 이동)
- **R-6** (삭제 — 폐기 정산은 부록 A로 이동)
- **R-7** 매각 정산에서 (받을 금액 합계) = 매각가. 반올림 오차로 불일치가 나면 최대 지분자에게 차액(±1원 단위)을 보정하고, 그래도 불일치면 오류 표시 후 결과를 신뢰 불가로 표시.
- **R-8** 금액은 정수 원 단위. 통화 표기는 "원"으로 고정.
- **R-9** 필수 입력 = 물건명, 총 구매금액(> 0), 참여자 ≥ 2, 분배 방식. **납부액 모드이면 참여자 전원의 납부액(≥ 0) 입력**. 구매일·관리자·합의 메모는 선택. 필수 누락 시 자산 생성 불가.
- **R-10** 낸 비용 합계는 표시 전용 정보이며 정산 계산에는 반영하지 않는다(MVP 결정).
- **R-11** 납부액 모드에서 납부액 합계가 0이면 지분 계산 불가 → 오류 표시, 자산 생성·정산 차단.
- **R-12** 참여자 삭제(다음 버전 기능)는 해당 참여자가 부담자·관리자로 참조되면 차단하거나 참조를 함께 정리한다. MVP에서는 생성 후 참여자 편집을 제공하지 않는다.
- **R-13** 관리자는 참여자 목록에 존재하는 1명만 지정 가능. 참여자가 목록에서 빠지면 관리자 지정도 해제된다.

## 부록 A. 다음 버전 정산 규칙 (참고 — 이번 MVP 구현 안 함)
- **인수 정산**: 인수자 지급액 = 현재 평가액 × (1 − 인수자 지분율). 나머지 구성원 받을 금액 = 현재 평가액 × 각자 지분율.
- **폐기 정산**: 분배 대상 = 잔존가치 − 폐기비용(음수 가능). 음수면 각 구성원이 지분율만큼 추가 지급.
- 두 규칙 모두 (받을 금액 합 − 낼 금액 합) = 분배 대상 금액 검증을 적용한다.
