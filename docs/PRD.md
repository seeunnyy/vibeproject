## 1. 개요

- **한 줄 정의**: 공동소유 자산의 지분과 비용을 기록하고, 합의된 규칙에 따라 공동소유를 종료(정산)하는 서비스.
- **제품 목표**: 룸메이트·동아리 구성원이 함께 구매한 물건의 소유 지분, 구매·유지비 부담 내역, 관리 책임, 향후 매각·인수·폐기 규칙을 한곳에 기록하도록 지원한다. 공동구매 시점의 합의를 앱에서 문서화하고, 이사·졸업·관계 변화 등 공동소유를 종료해야 하는 시점에 분쟁을 줄인다.
- **핵심 가치**: 구매 합의 → 보유 중 비용 기록 → 종료 시 정산까지를 **하나의 흐름**으로 연결한다.
- **형태**: 모바일 웹(반응형). 외부 시세·거래 API를 사용하지 않고, 사용자가 입력한 값과 사칙연산(+ − × ÷)만으로 동작한다.
- **콘셉트 학습 각도**: 실제 토큰 발행 없이 "지분 발행 · 가치 평가 · 청산"이라는 자산 토큰화의 핵심 개념을 일상적인 공동소유 사례로 체험하게 한다.

---

## 2. 배경

공동생활과 동아리 활동에서는 가구, 가전제품, 장비, 행사 물품 등을 여러 사람이 함께 구매하는 경우가 많다. 그러나 구매 당시 지분과 비용 분담을 구두로만 정하거나 메신저에 흩어 놓기 때문에, 시간이 지나면 다음을 확인하기 어렵다.

- 누가 얼마를 냈는지
- 현재 소유 비율이 어떻게 되는지
- 누가 물건을 관리해야 하는지

특히 이사, 졸업, 동아리 해산처럼 공동소유를 종료하는 시점에는 매각 금액과 잔존가치에 대한 의견 차이가 분쟁으로 이어진다.

우리몫은 자산 토큰화와 공동소유 개념을 초보자도 이해할 수 있도록, **단순한 지분 계산과 졸업 시뮬레이션**으로 제공하는 4주 구현 목표의 모바일 웹 서비스다. 초기 버전은 외부 시세·거래 API 없이 사용자가 입력한 값과 사칙연산만으로 동작하므로 4주 내 안정적인 구현과 시연이 가능하다.

## 3. 문제 및 해결 방안

### 3.1 사용자 문제

1. 공동으로 구매한 물건의 소유 지분과 비용 부담 내역이 명확하지 않다.
2. 시간이 지나며 추가 구매비·수리비·배송비 기록이 누락되어, 구성원별 실제 부담액과 소유 비율을 다시 계산하기 어렵다.
3. 공동생활이나 활동이 끝날 때 매각·인수·폐기 중 어떤 방식을 적용할지 미리 정하지 않아 정산 과정에서 갈등이 생긴다.

### 3.2 해결 방안

| 문제 | 해결 |
|---|---|
| 지분·부담 불명확 | 공동 자산을 등록하고 구매 금액·참여자·납부액(또는 균등 지분)을 입력하면 구성원별 지분을 자동 계산. 지분 합계 100% 즉시 검증. |
| 비용 기록 누락 | 자산별 합의사항과 비용 내역(항목·금액·부담자)을 기록. 누적 부담액과 초기 지분을 구분해 표시. |
| 종료 시 갈등 | 종료 시나리오로 **매각 · 한 명의 인수 · 폐기**를 제공하고, 현재 평가액을 입력하면 선택한 규칙에 따라 각 구성원이 받을 금액과 추가 지급액을 계산. |
| 합의 공유 | 모든 계산 결과와 합의 내용을 공유 가능한 요약 화면으로 제공. |

### 3.3 차별점

- 일반 가계부·정산 서비스가 **지출을 나누는 데** 집중하는 것과 달리, 우리몫은 **공동 자산 자체를 중심으로** 지분과 종료 규칙을 관리한다.
- 구매 시점의 합의부터 보유 중 비용 기록, 종료 시점의 정산까지 하나의 흐름으로 연결한다.
- 복잡한 금융 용어나 실제 토큰 발행 없이 자산 토큰화의 핵심 개념(지분 발행·가치 평가·청산)을 일상 사례로 체험할 수 있다.
- 외부 시세·거래 API 없이 입력값과 사칙연산만으로 동작해 4주 내 구현·시연이 가능하다.

## 4. 타겟 및 시나리오

### 4.1 타겟 사용자

| 구분 | 대상 | 특징 |
|---|---|---|
| 주요 | **룸메이트** | 냉장고·청소기·가구·공용 주방용품처럼 함께 쓰는 물건을 구매하며, 구성원별 납부액이 다를 수 있는 20~30대 대학생·사회초년생. |
| 주요 | **동아리 구성원** | 카메라·음향장비·행사 물품·공구처럼 여러 사람이 공동으로 사용하는 자산을 관리. |
| 부차 | **초보 학습자** | 공동소유 개념과 자산 토큰화의 기본 원리를 학습하려는 사용자. |

공통적으로 전문적인 회계·금융 지식이 없고, 모바일에서 빠르게 입력할 수 있는 간단한 서비스를 선호한다. 메신저 대화만으로 합의 내용을 관리하는 데 불편을 느끼며, 분쟁이 생기기 전에 기준을 남기고 싶어 한다.

### 4.2 핵심 시나리오

1. **공동구매 시작** — 함께 구매할 물건을 정하고 우리몫에서 자산을 생성한다. 물건명, 구매일, 총 구매금액, 참여자를 입력하고 각자의 납부액 또는 균등 지분을 설정한다.
2. **지분 확인** — 자산 상세 화면에서 구성원별 지분율, 납부액, 예상 권리 금액을 확인한다. 지분 합계가 100%인지 즉시 검증한다.
3. **공동비용 기록** — 수리비·추가 구매비가 발생하면 비용 내역과 부담자를 기록한다. 누적 부담액과 초기 지분을 구분해 보여준다.
4. **종료 규칙 합의** — 구매 직후 또는 보유 중에 매각·특정 구성원 인수·폐기 중 종료 방식을 선택하고, 평가액 산정 기준과 정산 방식을 기록한다.
5. **졸업·이사·동아리 해산** — 현재 평가액과 종료 방식을 입력하면 구성원별 받을 금액, 인수자가 지급할 금액, 부족하거나 추가로 필요한 정산액을 계산한다. 결과 요약을 공유해 최종 합의를 돕는다.

## 5. MVP 범위

### 5.1 포함 (In scope)

- 자산 생성 / 목록 / 상세
- 참여자 등록 및 지분 계산 (납부액 기반 또는 균등) + 지분 합계 100% 검증
- 공동비용 기록 (항목 · 금액 · 부담자 · 분담 방식) 및 구성원별 누적 부담액 표시
- 자산별 합의사항(자유 서술) 기록
- 종료 규칙 3종: **매각 / 한 명의 인수 / 폐기**
- 현재 평가액 입력 → 시나리오별 구성원 정산액 계산 (근거 식 함께 표기)
- 공유용 요약 화면 (읽기 전용)

### 5.2 제외 (Out of scope — MVP 이후)

- 계정/인증, 다중 기기 동기화, 실시간 공동 편집
- 외부 중고 시세 연동, 감가상각 자동 추정
- 알림/푸시, 결제·정산 이체 실행
- 다국어, 다크 모드

### 5.3 성공 기준 (시연 관점)

- 자산 1건에 대해 **생성 → 지분 확인 → 비용 2건 입력 → 3가지 종료 시나리오 결과**를 오차 없이 계산·공유할 수 있다.
- 지분 합계는 항상 100%로 검증되고, 정산 결과의 합계가 배분 대상 재원(매각가/평가액/잔존가치−폐기비용)과 정확히 일치한다.

### 5.4 가정 및 제약

- 금액은 KRW 정수(원)로 취급한다. 소수 지분 분배에서 생기는 나머지는 규칙적으로 배분한다(ARCHITECTURE.md 참조).
- 단일 통화, 단일 언어(한국어).
- 데이터는 사용 기기에 로컬 저장(MVP). 서버 동기화는 이후 단계.
