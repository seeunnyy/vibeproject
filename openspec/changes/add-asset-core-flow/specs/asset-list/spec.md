## Purpose

등록된 자산을 카드 목록으로 보여주고, 상태·참여자·물건명 검색어로 거르는 규칙과 빈 상태 표현을 정의한다.

## ADDED Requirements

### Requirement: 자산 목록 표시
The system SHALL 등록된 자산을 카드 목록으로 보여준다. 각 카드는 물건명, 참여자 수, 총 구매금액, 상태 배지, 관리자(있으면 이름, 없으면 "관리자 미지정")를 포함한다. 카드를 선택하면 해당 자산 상세로 이동한다.

#### Scenario: 자산이 있으면 카드로 나열
- **WHEN** 자산이 2건 저장되어 있고 사용자가 목록을 연다
- **THEN** 2개의 카드가 각각 물건명·참여자 수·총액·상태·관리자와 함께 표시된다

#### Scenario: 카드 선택 시 상세 이동
- **WHEN** 사용자가 목록에서 한 카드를 선택한다
- **THEN** 그 자산의 상세 화면으로 이동한다

#### Scenario: 등록된 자산이 없음
- **WHEN** 저장된 자산이 하나도 없다
- **THEN** "아직 등록한 자산이 없어요" 안내와 "자산 추가" 동작이 표시된다

### Requirement: 상태 필터
The system SHALL 목록을 상태로 거를 수 있게 한다: 전체 / 작성중 / 합의완료 / 정산완료. 기본값은 "전체"이다.

#### Scenario: 합의완료만 보기
- **WHEN** 사용자가 상태 필터에서 "합의완료"를 선택한다
- **THEN** 상태가 `agreed`인 자산만 목록에 남는다

### Requirement: 참여자 필터
The system SHALL 특정 참여자가 포함된 자산만 보도록 거를 수 있게 한다.

#### Scenario: 참여자로 거르기
- **WHEN** 사용자가 참여자 필터에서 "세은"을 선택한다
- **THEN** 참여자 목록에 "세은"이 있는 자산만 표시된다

### Requirement: 물건명 검색
The system SHALL 물건명 부분 일치(대소문자·앞뒤 공백 무시)로 목록을 거를 수 있게 한다.

#### Scenario: 물건명 일부로 검색
- **WHEN** 사용자가 검색어에 "냉장"을 입력한다
- **THEN** 물건명에 "냉장"이 포함된 자산만 표시된다

### Requirement: 필터 결합과 빈 결과
The system SHALL 상태·참여자·검색어 필터를 AND로 결합한다. 조합 결과가 0건이면 "조건에 맞는 자산이 없어요" 안내를 표시하며, 이는 "자산이 하나도 없음"과 구분한다.

#### Scenario: 여러 필터 동시 적용
- **WHEN** 상태 "작성중", 참여자 "지민", 검색어 "카메라"를 모두 지정한다
- **THEN** 세 조건을 모두 만족하는 자산만 표시된다

#### Scenario: 조건에 맞는 자산 없음
- **WHEN** 필터 조합에 해당하는 자산이 없다
- **THEN** "조건에 맞는 자산이 없어요" 안내와 함께 필터를 초기화하는 동작이 제공된다
