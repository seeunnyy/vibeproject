## Purpose

공동소유 자산 1건을 만들기 위한 입력 항목, 지분율 산출, 납부액 합계 검증, 관리자 지정 규칙을 정의한다. 생성된 자산은 항상 `draft`(작성중) 상태로 시작한다.

## ADDED Requirements

### Requirement: 자산 생성 필수 입력
The system SHALL 물건명, 총 구매금액(> 0), 참여자 2명 이상, 분배 방식이 모두 입력된 경우에만 자산을 생성한다. 구매일·관리자·합의 메모는 선택 입력이다. 분배 방식이 "납부액"이면 참여자 전원의 납부액(≥ 0)을 추가로 요구한다.

#### Scenario: 필수 입력이 모두 채워지면 생성 가능
- **WHEN** 사용자가 물건명 "공용 냉장고", 총 구매금액 900,000, 참여자 3명, 분배 방식 "납부액", 각 참여자 납부액을 입력한다
- **THEN** "자산 만들기" 동작이 활성화되고, 실행 시 자산이 저장되며 자산 상세 화면으로 이동한다

#### Scenario: 필수 입력 누락 시 생성 불가
- **WHEN** 물건명이 비어 있거나, 총 구매금액이 0 이하이거나, 참여자가 1명이거나, 분배 방식이 선택되지 않았다
- **THEN** "자산 만들기" 동작이 비활성화되고 누락 항목에 대한 안내가 표시된다

#### Scenario: 납부액 모드에서 납부액 누락 시 생성 불가
- **WHEN** 분배 방식이 "납부액"인데 참여자 중 한 명 이상의 납부액이 비어 있다
- **THEN** "자산 만들기" 동작이 비활성화된다

### Requirement: 지분율 자동 산출
The system SHALL 각 참여자의 지분율(%)을 분배 방식에 따라 자동 계산한다. "납부액" 모드는 `참여자 납부액 ÷ 납부액 합계`, "균등" 모드는 `100 ÷ 참여자 수`로 계산한다. 표시는 소수 첫째 자리에서 반올림하고, 반올림 잔여는 납부액이 가장 큰 참여자(균등이면 첫 참여자)에게 배분해 합계를 100%로 맞춘다.

#### Scenario: 납부액 비율로 지분 계산
- **WHEN** 총 구매금액 900,000, 납부액이 450,000 / 300,000 / 150,000 으로 입력된다
- **THEN** 지분율이 50.0% / 33.3% / 16.7% 로 표시되고 합계는 100.0% 이다

#### Scenario: 균등 분배
- **WHEN** 참여자가 3명이고 분배 방식이 "균등"이다
- **THEN** 지분율이 33.4% / 33.3% / 33.3% 로 표시되고 합계는 100.0% 이다

### Requirement: 납부액 합계 검증
The system SHALL "납부액" 모드에서 참여자 납부액의 합계가 총 구매금액과 일치하는지 표시한다. 일치하면 확인 상태, 다르면 경고 상태와 차액(원)을 보여준다. 검증 실패 자체는 자산 생성을 막지 않는다. (합계가 0인 경우는 예외 — 아래 시나리오)

#### Scenario: 합계가 총 구매금액과 일치
- **WHEN** 총 구매금액 900,000, 납부액 합계가 900,000 이다
- **THEN** "납부액 합계가 총 구매금액과 일치합니다" 확인 표시가 나타난다

#### Scenario: 합계가 총 구매금액보다 적음
- **WHEN** 총 구매금액 900,000, 납부액 합계가 850,000 이다
- **THEN** "총 구매금액보다 50,000원 적습니다" 경고와 차액이 표시되며, 생성은 여전히 가능하다

#### Scenario: 납부액 합계가 0
- **WHEN** 분배 방식이 "납부액"인데 전원 납부액이 0이어서 합계가 0이다
- **THEN** 지분을 계산할 수 없다는 오류가 표시되고 "자산 만들기"가 비활성화된다

### Requirement: 관리자 지정
The system SHALL 참여자 목록에 있는 1명을 관리자로 지정하거나 "없음"으로 둘 수 있게 한다. 관리자는 목록·상세에서 라벨로 표시되며 다른 참여자와 권한 차이는 없다.

#### Scenario: 생성 시 관리자 지정
- **WHEN** 사용자가 참여자 "지민"을 관리자로 선택하고 자산을 만든다
- **THEN** 자산 상세와 목록 카드에 "관리자: 지민"이 표시된다

#### Scenario: 관리자 미지정
- **WHEN** 사용자가 관리자를 "없음"으로 두고 자산을 만든다
- **THEN** 자산에 "관리자 미지정"이 표시된다

### Requirement: 생성 시 초기 상태
The system SHALL 새로 생성된 모든 자산의 상태를 `draft`(작성중)로 설정한다.

#### Scenario: 새 자산은 작성중
- **WHEN** 사용자가 유효한 입력으로 자산을 생성한다
- **THEN** 그 자산의 상태는 `draft` 이다
